# Zoning

Python program to solve the harvest zoning problem.

- MIP and DP formulations live in `solvers.py`
- Code for making zones lives in `zoning.py`
- Code for reading in field data lives in `data_processing.py`
- `cli.py` contains code to set up the command line interface using click.
  If you want to use it yourself you're need to install this library as an editable package with `pip install -e` (I think)

Enjoy.
